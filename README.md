# Advanced Network Security Labs

This repository contains Cisco Packet Tracer laboratory exercises completed as part of the Advanced Network Security course at Sunway University.

## Topics Covered

- Device Hardening
- Secure Passwords
- SSH Configuration
- Syslog
- Network Time Protocol (NTP)
- AAA Authentication
- TACACS+
- RADIUS
- Standard ACLs
- Extended ACLs
- Zone-Based Policy Firewall (ZPF)
- Cisco ASA Firewall
- Port Security
- Layer 2 VLAN Security
- OSPF Authentication
- GRE Tunnel
- IPSec VPN

## Software Used

- Cisco Packet Tracer
- Cisco IOS CLI
- Cisco ASA Firewall

## Skills Demonstrated

- Router Configuration
- Switch Configuration
- Network Hardening
- Access Control
- Firewall Deployment
- VPN Configuration
- Authentication and Authorization
- Secure Network Design
